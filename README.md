# Wypożyczalnia gier i konsol

System do obsługi wypożyczania gier planszowych/wideo oraz konsol: katalog
dostępnych pozycji, rezerwacje, kolejkowanie, wypożyczenia i zwroty, naliczanie
opłat oraz powiadomienia dla klientów.

## Temat

Projekt systemu **wypożyczalni gier i konsol** — zarządzanie katalogiem i stanami
magazynowymi, kontami klientów, procesem wypożyczenia (7/14/30 dni),
kolejkowaniem niedostępnych egzemplarzy, kaucjami i rozliczeniami oraz
integracją z płatnościami i kurierami (paczkomaty).
